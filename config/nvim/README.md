# My Neovim Configuration

**NOTE:** This configuration uses AstroNvim v6+.

My personal Neovim configuration built on top of [AstroNvim](https://github.com/AstroNvim/AstroNvim).

## Installation

### Make a backup of your current nvim and shared folder

```shell
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak
mv ~/.cache/nvim ~/.cache/nvim.bak
```

### Clone the repository

```shell
git clone --depth 1 https://github.com/rolodoom/dotfiles ~/.config/nvim
```

### Start Neovim

```shell
nvim
```
